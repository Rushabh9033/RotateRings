# DESIGN.md — Rotate Rings Visual & Aesthetic Tokens

## 1. Color Palette
- **Background Dark:** `#0F111A` (Deep Slate Navy)
- **Background Card/Board:** `#181B28` (Dark Surface)
- **Ring Outer Color:** `#4E95FF` (Vibrant Cyan Blue)
- **Ring Mid Color:** `#FFB224` (Warm Amber Gold)
- **Ring Inner Color:** `#FF4A75` (Electric Coral Pink)
- **Ring Accent / Glow:** `#00FFA3` (Neon Emerald)
- **Exit Marker / Arrow:** `#FFFFFF` (Crisp White)
- **Success Particle Spark:** `#FFE866` (Golden Sun)

## 2. Typography & Text Hierarchy
- **Font Family:** System Sans-Serif / Clean Modern Geometric Sans
- **Title (H1):** 36px, Bold (700)
- **Level Subtitle (H2):** 24px, Medium (600)
- **HUD / Buttons:** 18px, Medium (500)
- **Stats / Counters:** 14px, Regular (400)

## 3. Spacing & Geometry Scale
- **Spacing Scale:** 4 / 8 / 12 / 16 / 24 / 32 / 48 px
- **Ring Line Width:** 18px - 24px with rounded end-caps (`line_cap = ROUND`)
- **Gap Angle Width:** ~45° to 60° (0.78 to 1.05 radians)
- **Ring Radii Scale:** Inner = 70px, Mid = 120px, Outer = 170px, Ultra = 220px
- **Border Radius:** sm=6px, md=12px, lg=20px, full=9999px
- **Shadows:** Subtle dark radial glow (`#00000044`, radius 15px)
