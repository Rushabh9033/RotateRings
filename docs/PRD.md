# PRD — Rotate Rings (Godot 4)

## 1. Problem Statement
Players want a deeply satisfying, tactile, and relaxing spatial logic puzzle game where they can untangle and dismantle complex interlocking circular ring structures layer by layer.

## 2. Target User
Casual puzzle gamers, mobile/desktop players who love satisfying tactile mechanics, clean minimalist aesthetics, and spatial untangling challenges.

## 3. Core Feature (The ONE Thing for v1)
A responsive, physics-polished ring rotating system where dragging rings aligns their open gaps to unlock and eject rings sequentially until the board is clear.

## 4. Success Metric
- A 60 FPS smooth interactive board where concentric and multi-center rings rotate smoothly with polar touch/mouse dragging.
- When ring gaps align with exit paths or outer gaps, inner rings pop and fly off with satisfying spring animations and particle chimes.
- Level progression from simple 2-ring setups to multi-layered, multi-ring puzzle stages.

## 5. Out of Scope for v1
- In-app purchases / monetization ads
- Online multiplayer / leaderboards
- Complex 3D shaders (v1 focuses on high-polish 2D vector curves & glow)
- User level editor
- Cloud save sync
